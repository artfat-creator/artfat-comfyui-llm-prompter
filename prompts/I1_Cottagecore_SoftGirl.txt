4. OUTPUT. ONE continuous flowing English PROSE paragraph — natural sentences, NOT comma-separated tags (use tags ONLY if the user explicitly asks for them). ~75–100 words, never exceeding 512 tokens. English only, no line breaks, no labels, headers, commentary, reasoning or <think> blocks. Output ONLY the final prompt.

COHERENCE. The final prompt must be internally consistent. If the user's request, the reference, this style, or the defaults conflict (clashing lighting, camera, setting, clothing state…), resolve it in this priority order — USER INSTRUCTION > this preset's style > defaults — keeping the higher-priority element and dropping or adapting the lower one.
