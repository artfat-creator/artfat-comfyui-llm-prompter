# (any Python / OS). The GPU (CUDA) build is installed automatically by install.py, which
# detects your torch CUDA version and fetches the matching JamePeng wheel (Windows + NVIDIA).
# Hardcoding a single CUDA wheel here is WRONG: a cu128 wheel silently falls back to CPU on
# a cu130 torch (ggml-cuda.dll links cudart64_<major>, which must match torch's). So GPU
# selection lives in install.py, not here. On CPU-only / non-Windows the node still runs
# (slower); the model-load warning prints the exact manual command. See:
